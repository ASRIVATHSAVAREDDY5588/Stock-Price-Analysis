# AI & Financial Limitations: Stock Market Distribution Analyzer

## 1. Educational Signal Rubric

The **Stock Market Distribution Analyzer** includes an educational signal generator that categorizes historical evidence into one of three discrete actions: **BUY**, **HOLD**, or **SELL**.

### Deterministic Baseline Scoring Model
Alongside any LLM-driven commentary, the application computes an objective, rule-based quantitative baseline score ranging from **-1.0 to +1.0**:

$$\text{Score} = \text{Trend} + \text{Drawdown Penalty} + \text{Benchmark Alpha} + \text{Volatility Adjustment}$$

1. **Trend & Momentum ($\pm 0.40$):**
   - $+0.20$ if Current Price $>$ 20-day Simple Moving Average (SMA); else $-0.20$.
   - $+0.20$ if Current Price $>$ 50-day Simple Moving Average (SMA); else $-0.20$.
2. **Drawdown Penalty ($0.0$ to $-0.30$):**
   - $-0.05$ if current drawdown from peak $< -5\%$.
   - $-0.15$ if current drawdown from peak $< -15\%$.
   - $-0.30$ if current drawdown from peak $< -25\%$.
3. **Benchmark Relative Alpha ($\pm 0.20$):**
   - Compares asset total return over the period against the NIFTY 50 benchmark.
   - $+0.20$ if excess return $> +10\%$; $-0.20$ if excess return $< -10\%$.
4. **Volatility Regime Adjustment ($\pm 0.15$):**
   - $+0.10$ if annualized volatility $< 20\%$ (orderly price action).
   - $-0.15$ if annualized volatility $> 35\%$ (excessive dispersion penalty).

### Decision Thresholds
- **BUY:** Composite Score $\ge +0.25$.
- **SELL:** Composite Score $\le -0.25$.
- **HOLD:** $-0.25 < \text{Composite Score} < +0.25$, or when data quality conditions mandate a neutral stance.

## 2. Confidence Level Definitions

The confidence label attached to each signal describes **the statistical quality, consistency, and sample size of the historical evidence**. It does **NOT** represent the probability of future investment profit.

| Confidence Level | Criteria / Data Quality Condition |
| :--- | :--- |
| **`HIGH`** | Historical observations $N \ge 250$ (1+ full year), consistent alignment between trend and momentum indicators, and moderate drawdown risk. |
| **`MEDIUM`** | $60 \le N < 250$ observations, or moderate divergence between momentum indicators and drawdown. |
| **`LOW`** | Conflicting technical evidence (e.g., strong multi-month momentum accompanied by a severe recent drawdown) or high volatility ($\sigma_{\text{ann}} > 35\%$). |
| **`INSUFFICIENT_EVIDENCE`** | Observation count $N < 60$ daily sessions, significant missing observation gaps, or synthetic test profiles with indeterminate direction. |

## 3. Server-Side Grounding & Anti-Hallucination Guardrails

To prevent language model hallucinations:
1. **Server-Side Validation:** The server intercepts all candidate outputs from the OpenAI SDK before they reach the user.
2. **Numeric Anchor Verification:** Floating-point numbers extracted from the rationale or supporting items are matched against verified server-side statistics (Mean, Volatility, VaR, MDD, Beta). Any fabricated metrics or targets are flagged.
3. **Automatic Downgrade Rules:** If the dataset has fewer than 60 observations, the server overrides any LLM output to **`HOLD / INSUFFICIENT_EVIDENCE`**.
4. **Prohibited Content Filter:** The system detects and strips promotional phrasing, target prices, position-sizing advice, or guarantees of profit.

## 4. Epistemological & Statistical Limitations

1. **Non-Stationarity of Financial Markets:** Statistical distributions fitted to past returns assume stationarity over the chosen window. In reality, market regimes, monetary policies, and macroeconomic environments change over time.
2. **Distribution Testing Caveat:** High p-values on Kolmogorov-Smirnov or Jarque-Bera tests, or a lower AIC on a Student-t fit, indicate that a model is a **closer approximation** of the historical sample than a baseline Gaussian curve. It **does not prove** that stock returns literally follow that mathematical equation in nature.
3. **Period Dependence of Risk:** Value at Risk (VaR), Expected Shortfall, and Maximum Drawdown are conditional on the historical sample period selected. A date window that excludes major systemic shocks (e.g., the 2008 global financial crisis or March 2020 pandemic decline) will substantially understate future downside tail risk.
